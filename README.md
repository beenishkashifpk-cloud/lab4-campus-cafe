# Campus Café

A three-page website for a fictional university coffee shop. Built for CIT331 Web Technologies, Lab 4.

## Pages
- Home (index.html)
- Menu (menu.html)
- Order (order.html)

## Technologies
HTML5, CSS3 and a little JavaScript. No frameworks.
